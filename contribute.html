Choose a piece and let an AI coding agent do the notation work.

Get started

  1. Choose a printed, public-domain edition from IMSLP or another reliable library. Do not use a handwritten manuscript.
  2. Clone the repository.
git clone https://github.com/dhruv9saini/the-opus-project.git
  1. Open the repository in Codex, Claude Code, or another coding agent and ask it to transcribe a specific work—or simply ask it to help The OPUS Project until your usage runs out.
  2. Let the agent follow AGENTS.md, compile the LilyPond, and open a pull request.

The five steps

Steps 1–4 are independent transcriptions. Each must be produced by a different agent, and an agent must not inspect the earlier attempts before submitting its own. This gives the final reviewer several genuinely independent readings of the source.

Agents must read the printed edition visually and enter LilyPond directly. Optical music recognition, OCR-to-score tools, MusicXML or MIDI conversion, and existing digital transcriptions are not allowed.

Step 5 is a meta-review. A final agent compares all four LilyPond files against the printed edition, resolves disagreements, and produces the publication copy.

Pull request details

Every transcription pull request must identify its step, the exact model that produced it, and the printed source:

Step: 1/5
Model: provider/exact-model-id
Source: https://example.org/printed-edition

The checks compile every score, verify the metadata and generated catalog, and reject a transcription pull request when those annotations are missing. After the pull request is merged, GitHub Pages regenerates the catalog and deploys the website automatically.

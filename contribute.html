Contribute

Add a transcription with an AI coding agent, or proofread one.

Add a new transcription

  1. Choose a printed, public-domain edition from IMSLP or another reliable library. Do not use a handwritten manuscript.
  2. Clone the repository.
git clone https://github.com/the-opus-project/the-opus-project.github.io.git
  1. Open the repository in Codex, Claude Code, or another coding agent. Ask it to transcribe a specific work, or to help The OPUS Project until your usage runs out.
  2. The agent follows AGENTS.md: it transcribes the work, checks its render against the scan, and opens a pull request.

How a score is made

In steps 1 and 2, two agents transcribe the work separately, without seeing each other's files. Each one checks its render against the scan and corrects what it finds.

Agents read the printed music and write LilyPond by hand. Music recognition (OMR) tools, MusicXML or MIDI conversion, and existing digital editions are not allowed.

In step 3, a third agent compares both versions with the scan, settles every difference, and writes score.ly. The score is marked "Needs proofreading" until a person checks it.

Proofread in Score Desk

Open a work in Score Desk. You can:

  1. Mark errors. Compare the score with the scan, mark each error, and note which pages you checked.
  2. Have an AI fix them. Choose Get correction package, give the ZIP and instructions to your AI, then load its answer with Return AI response.
  3. Check the fixes. For each change, choose Looks correct, Still needs correction, or Needs clarification.

Sending reviews to the project from Score Desk isn't switched on yet. Your work is saved in your browser, and you can post a report on the score's Compare PDFs page.

Pull request details

A transcription pull request lists the step, the exact model, and the printed source:

Step: 1/3
Model: provider/exact-model-id
Source: https://example.org/printed-edition

A proofreading pull request uses Review: human, Proofreader: @github-name, and the source URL instead.

Automatic checks compile every score and reject pull requests without these fields.

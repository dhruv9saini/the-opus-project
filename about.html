About The OPUS Project

Open Public-domain Universal Scores.

A crowdsourced project to transcribe the world's music with AI.

The project

Printed scores preserve an enormous part of the world's musical history, but scans are difficult to edit, search, hear, or turn into new editions. The OPUS Project turns those public-domain editions into open LilyPond source files.

Anyone can choose a score, clone the repository, and ask an AI coding agent to do the notation work. Contributions are ordinary pull requests: the source edition, LilyPond file, generated PDF, progress step, and model used are all visible.

How the review works

Two agents independently transcribe the same printed score without reading one another's work. A third agent compares both versions with the source and reconciles them into a LilyPond score. A human then proofreads the rendered PDF against the original scan.

The catalog shows agent progress, which scores need proofreading, and which have been checked by a person. An AI pass is never presented as human-verified.

One open archive

The LilyPond sources, rendered PDFs, source references, and review history live together in the GitHub repository. When a contribution is merged, the catalog is rebuilt from the repository and the piece appears here automatically.

To help proofread, open a work's Compare PDFs link in the catalog. It puts the original scan and rendered transcription together; no repository clone or notation software is needed to inspect them.

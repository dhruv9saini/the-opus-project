About score@home

A crowdsourced project to transcribe the world's music with AI.

The project

Printed scores preserve an enormous part of the world's musical history, but scans are difficult to edit, search, hear, or turn into new editions. score@home turns those public-domain editions into open LilyPond source files.

Anyone can choose a score, clone the repository, and ask an AI coding agent to do the notation work. Contributions are ordinary pull requests: the source edition, LilyPond file, generated PDF, progress step, and model used are all visible.

How the review works

Every piece moves through five steps. Steps 1–4 are independent transcriptions made by different agents without reading one another's work. At Step 5, another agent compares all four versions against the printed source and reconciles them into the published score.

The catalog shows exactly where each piece is in that process. A first pass is useful, but it is never presented as a verified edition.

One open archive

The LilyPond sources, rendered PDFs, source references, and review history live together in the GitHub repository. When a contribution is merged, the catalog is rebuilt from the repository and the piece appears here automatically.

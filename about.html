About The OPUS Project

Open Public-domain Universal Scores.

A crowdsourced project to transcribe the world's music with AI.

The project

Many public-domain scores are available only as scans. This project encodes one printed edition at a time in LilyPond, so the notation can be edited and rendered from source.

Contributors clone the repository and ask an AI coding agent to transcribe a work. Each pull request names the scan and the model used.

How the review works

Two agents transcribe the same printed score without seeing each other's work, and each checks its render against the scan. A third agent compares the two versions with the scan and settles every difference. Then a person checks the whole score.

A score is marked as checked only after a person has compared every page. Mistakes in the printed edition are kept as printed and noted separately.

Files

The LilyPond files are the source of truth. The PDFs are rendered from them, and the site is rebuilt whenever a change is merged.

To proofread, open a work's Compare PDFs link. It shows the scan and the transcription side by side, so you don't need to install anything.
